v12.0.7.0 | 2026-07-11 | Modernized for Midnight (12.0.7)

TOC updated to Interface 120007; added IconTexture and addon category.
Bank rework (11.2): the character bank is now scanned as tab containers
  (bags 6-11) via C_Container/C_Bank. The old main-bank window slots, the
  7th bank bag, the reagent bank and void storage were removed from the
  game; their saved data remains viewable for characters that never
  logged in after the rework, and is cleared for a character the first
  time it opens the new bank.
Item API moved to C_Item (GetItemInfo/GetItemCount/GetItemIconByID);
  GetAddOnMetadata/IsAddOnLoaded moved to C_AddOns.
All dropdowns rewritten from UIDropDownMenu (removed) to the modern Menu
  API (DropdownButton/SetupMenu).
Options panel registered through the Settings API instead of the removed
  InterfaceOptions_AddCategory; checkboxes moved off the removed
  InterfaceOptionsCheckButtonTemplate.
Removed events (PLAYERREAGENTBANKSLOTS_CHANGED, REAGENTBANK_UPDATE,
  VOID_*, etc.) are no longer registered; registrations of uncertain
  events are guarded with C_EventUtils.IsEventValid.
Removed the "Open BankItems bags with Blizzard bags" option; it relied
  on replacing updateContainerFrameAnchors(), which no longer exists.
Warband (account) bank tracking: the warband bank is recorded as its own
  entry in the character dropdown (its five tabs, real containers 12-16,
  are stored as Bag6-Bag10). It is scanned whenever the bank is open,
  always passes realm/faction filters, and its gold and item counts are
  included in the total-gold and item tooltips, search and export.
Fixed: the Options button now opens the settings panel via the numeric
  category ID (Settings.OpenToCategory ignores name strings).
Fixed: selecting a character/guild in the data deletion dropdowns errored
  because the Menu API passes extra callback arguments; the confirmation
  popup is also raised above the Settings panel so it can't hide behind it.
The void storage and reagent bank buttons, their options checkboxes and
  the data broker tooltip shortcuts are now hidden unless a character
  still has legacy data recorded for them.
Fixed: clicking a bank tab (character or warband) did nothing -- the
  classic bag windows only support 36 slots and errored on 98-slot tabs;
  tabs now open in the shared 98-slot viewer frame (formerly the reagent
  bank frame), one tab at a time like the game's own bank UI. The quick
  search overlay code had the same 36-slot assumption and silently broke
  the rest of the main window; fixed.
Fixed: "data not found" chat/frame spam when selecting the warband entry
  or when "/bi" auto-open behaviors included the removed reagent bank /
  void storage; those are now skipped unless legacy data exists, and the
  warband entry only auto-opens its bank tabs.
Known gaps: the 28-slot main bank area of the window is only populated
  for legacy data.

v12.0.7.1 | 2026-07-12 | Main window rebuilt around the 98-slot bank tabs

The main window's old 28-slot legacy bank grid (only ever populated for
  characters that never revisited the bank after the 11.2 rework) is
  replaced by the modern 98-item tab-based bank storage, shown inline.
The shared 98-slot tab viewer (formerly a separate popup window used for
  bank tabs and the legacy reagent bank) is now embedded directly in the
  main window instead of opening on its own.
Added a vertical bank tab sidebar, modeled on the Guild Bank's own tab
  list: click a tab (up to 6 for a character, 5 for the warband bank) to
  switch the embedded viewer to it in place.
The character bank tab icons that used to sit in the "bags" row below
  the item grid are gone, replaced by the sidebar above. The remaining
  bag icons (backpack, bags 1-5, equipped, mail, currency, auction
  house, legacy reagent bank) stay as a compact row and still open their
  own classic bag windows.
Void Storage support (frame, buttons, save/populate functions, options
  checkbox, data broker tooltip lines) is removed entirely -- the
  feature no longer exists in the game as of 11.2. Legacy Bag104 data
  saved by older versions of the addon is left in place but unused.
Main window resized (403x430 -> 810x520) with a plain tiled background,
  since the embedded tab viewer supplies its own Bank-style art.
