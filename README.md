# BankItems
Keep track of your inventory, bank, mail, equipped items and more across all your characters.

Updated for **Midnight (12.0.7)**: works with the tab-based character bank introduced in patch 11.2 and tracks the **warband (account) bank**, which appears as its own entry in the character dropdown. Reagent bank and void storage were removed from the game; data recorded for them by older versions can still be viewed for characters that haven't logged in since the rework. See `CHANGES.txt` for details.
